# Data

Nothing in this folder is committed. Place the hackathon datasets here:

```
data/raw/DrugSensitivity/   LINCS L1000 level 4 (.gctx + StandardAnnotations),
                            CCLE expression, PharmacoDB mapping file
data/raw/Bioactivity/       ChEMBL release 37
data/processed/             outputs of the pipeline
```

Sources: LINCS (lincsportal.ccs.miami.edu), DepMap/CCLE (depmap.org), PharmacoDB, ChEMBL 37 (ftp.ebi.ac.uk/pub/databases/chembl/ChEMBLdb).
